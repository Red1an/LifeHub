# Как сделать модуль LifeHub с помощью нейронки

Подходит любая нейронка: Claude, ChatGPT и другие.

1. Скопируйте в чат всё, что ниже линии, **до конца файла**.
2. В самом конце, после слов «МОЯ ЗАДАЧА», опишите, какой модуль нужен. Пишите подробно: что он делает,
   какие экраны, что хранить, нужен ли виджет на главной.
   Чтобы **доработать** существующий модуль, вставьте туда же его файлы и опишите, что изменить.
3. Нейронка выдаст файлы модуля. Создайте папку `~/.lifehub/modules/<id>`, где `<id>` — это `id`
   из `lifehub.json`. На Windows это `C:\Users\<вы>\.lifehub\modules\<id>`. Разложите файлы в папку
   по указанным путям. Хаб подхватит модуль сам, перезапускать ничего не нужно.
   Второй способ — упаковать папку в zip и установить через «Модули → Добавить → Из файла».
4. Если модуль не собирается, хаб покажет ошибку и кнопку «Скопировать для Claude Code».
   Вставьте этот текст обратно в тот же чат, и нейронка исправит.

Если у вас Claude Code, проще открыть в нём папку `~/.lifehub/modules`: там уже лежит полная
инструкция, и Claude Code сам проверит сборку.

---

Ты пишешь модуль для LifeHub — личного хаба мини-приложений. Хаб работает на компьютере пользователя
и открывается в браузере на компьютере и на телефоне. Модуль — это маленькое приложение внутри хаба.
Строго следуй спецификации ниже: хаб собирает модуль сам, и любой код вне этих правил не заработает.

## 1. Что такое модуль

Папка с исходниками. `npm install`, `node_modules`, `package.json`, конфигов сборщика и `tsconfig.json`
в ней нет. Хаб сам компилирует TypeScript/TSX (esbuild) и подставляет React и SDK.

```
<id>/
  lifehub.json        манифест (обязателен)
  CLAUDE.md           описание модуля для нейронок
  src/index.tsx       точка входа (обязателен)
  src/...             другие .ts / .tsx / .css / .json файлы, если нужны
```

Маленький модуль может целиком жить в `src/index.tsx`. Если кода больше примерно 400 строк, разбей его
на файлы (`src/pages/…`, `src/components/…`, `src/lib/…`) с относительными импортами без расширения:
`import { Stats } from "./pages/Stats"`.

## 2. Манифест lifehub.json

```json
{
  "id": "water",
  "name": "Вода",
  "version": "0.1.0",
  "description": "Сколько воды выпито за день",
  "icon": "💧",
  "author": "имя автора",
  "type": "app",
  "sdk": "^1",
  "entry": "src/index.tsx",
  "deps": {},
  "permissions": [],
  "exports": { "collections": [] }
}
```

- `id` — латиница в нижнем регистре, цифры и дефис, начинается с буквы, от 2 до 41 символа. Совпадает с именем папки.
- `icon` — один эмодзи.
- `deps` — npm-пакеты, например `{ "marked": "^16" }`. **Добавляй только если без пакета никак**
  (см. раздел 4). Импорт пакета, которого нет в `deps`, — ошибка сборки.
- `permissions` — только нужные: `"files"` (хранить файлы), `"mic"` (микрофон), `"camera"`,
  `"notifications"`, `"ai"` (нейронка), `"read:<id другого модуля>"` (читать его данные).
- `exports.collections` — какие коллекции модуль разрешает читать другим модулям. Обычно пусто.

## 3. Точка входа src/index.tsx

```tsx
import { defineModule } from "@lifehub/sdk";

function Home() { /* … */ }
function Stats() { /* … */ }
function Item() { /* … */ }
function SummaryWidget() { /* … */ }

export default defineModule({
  routes: {
    "/": Home,                 // обязателен
    "/stats": Stats,
    "/items/:id": Item,        // параметр: useParams() → { id }
  },
  nav: [                       // разделы модуля: вкладки на компьютере и нижнее меню на телефоне, до 5 штук
    { to: "/", label: "Главная", icon: "🏠" },
    { to: "/stats", label: "Статистика", icon: "📊" },
  ],
  widgets: {                   // необязательно: карточки на главной странице хаба
    summary: { title: "Вода", size: "sm", component: SummaryWidget },   // size: "sm" | "md" | "lg"
  },
  theme: "dark",               // необязательно: своя тема модуля ("dark" | "light"), иначе — тема пользователя
});
```

Навигация — на выбор: `nav` (хаб нарисует нейтральные вкладки сверху на компьютере и нижнее меню
на телефоне) или своя навигация внутри модуля в его стиле (тогда `nav` не указывай).
Ссылку «назад в хаб» не делай — она есть в полосе хаба над модулем.

## 4. Что доступно для импорта

Импортировать можно **только**:
- `react` (React 19: хуки, `useState`, `useEffect`, `useMemo`, `useRef`…);
- `@lifehub/sdk` — всё перечисленное ниже;
- свои файлы модуля;
- пакеты, объявленные в `deps`.

Нельзя: модули Node.js (`fs`, `path`…), `react-router`, тяжёлые UI-фреймворки (MUI, Ant Design,
Chakra — оформляй через Tailwind и свой CSS), `axios`, `date-fns`/`dayjs`/`moment` для простых вещей
(в SDK есть форматирование дат), CDN-скрипты, `localStorage`/`IndexedDB` для данных. Данные только через SDK: иначе они не
появятся на другом устройстве.

## 5. API @lifehub/sdk

### Данные (хранятся в хабе и синхронизируются между устройствами)

```tsx
import { useCollection, useDoc, useStore, db, kv, dayKey } from "@lifehub/sdk";

interface Drink { amount: number; date: string }     // только JSON-данные; даты — строками или числами

// Коллекция документов. Каждый документ получает id, createdAt, updatedAt (мс).
const drinks = useCollection<Drink>("drinks");
drinks.items;      // (Drink & { id, createdAt, updatedAt })[] — в порядке создания
drinks.loading;    // true, пока данные грузятся
drinks.error;      // string | null
await drinks.add({ amount: 250, date: dayKey() });   // вернёт документ; можно передать свой id: { id: "...", ... }
await drinks.update(id, { amount: 300 });            // слияние полей
await drinks.put(id, { amount: 300, date: "2026-09-25" });  // полная замена или создание с заданным id
await drinks.remove(id);
await drinks.clear();

// Один документ по id:
const { doc, loading, update, remove } = useDoc<Drink>("drinks", id);

// Как useState, но значение сохраняется и одинаково на всех устройствах (настройки, цели):
const [goal, setGoal] = useStore<number>("goal", 2000);
// setGoal(2500) или setGoal(prev => prev + 250)

// Вне компонентов:
const all = await db.collection<Drink>("drinks").list();   // также get, add, update, put, remove, clear
const v = await kv.get<number>("goal", 2000);
await kv.set("goal", 2500);
```

Имена коллекций и ключей: только `a-z A-Z 0-9 _ -`. Фильтрация и сортировка — на клиенте
(`drinks.items.filter(...)`), этого хватает на десятки тысяч записей.

Читать чужие данные можно, только если модуль-владелец указал коллекцию в `exports.collections`,
а в своём манифесте есть `"read:<id>"`:
`useCollection<T>("transactions", { from: "finance" })`. Такие данные доступны только на чтение.

### Файлы (разрешение "files")

```tsx
import { files, useFiles } from "@lifehub/sdk";
const meta = await files.upload(blob, "фото.jpg");   // { id, name, mime, size, createdAt }
<img src={files.url(meta.id)} />
const { files: list, loading } = useFiles();
await files.remove(id);
```

Храни в документе коллекции `fileId`, а не сам файл.

### Нейронка (разрешение "ai")

Запросы выполняет Claude Code пользователя на компьютере с хабом (API-ключ не нужен, работает и с телефона).
Claude отвечает только текстом, без доступа к файлам.

```tsx
import { ai, useAi } from "@lifehub/sdk";
const text = await ai.ask("вопрос", { system: "роль и правила", model: "fast" | "smart", onDelta: (d, full) => {} });
const data = await ai.json<{ title: string }[]>("… верни массив [{\"title\": \"…\"}]");
const reply = await ai.chat([{ role: "user", content: "…" }, { role: "assistant", content: "…" }, { role: "user", content: "…" }]);
const { run, text, loading, error, cancel } = useAi();   // в компоненте: await run(prompt, { system })
```

Всегда показывай загрузку, сохраняй полезные ответы в коллекцию, ошибку (например «Claude Code не авторизован»)
показывай пользователю как есть.

### Навигация (пути внутри модуля)

```tsx
import { Link, useNavigate, useParams, useLocation, useSearchParams } from "@lifehub/sdk";
<Link to="/stats">Статистика</Link>
<Link to="/" activeClassName="text-accent" end>Главная</Link>
const navigate = useNavigate();  navigate("/items/42");  navigate(-1);  navigate("/", { replace: true });
const { id } = useParams<{ id: string }>();
const { pathname, search } = useLocation();                    // pathname внутри модуля, например "/stats"
const [params, setParams] = useSearchParams();  params.get("q");  setParams({ q: "текст", page: null });
```

Пути в `to` и `navigate` пиши от корня модуля (`"/stats"`), хаб сам добавит префикс модуля.
Обычные `<a href>` для переходов внутри модуля не используй.

### Готовые компоненты (необязательные)

Нейтральный набор, который следует теме и акценту хаба. Используй его для служебных частей или для
модуля без особого дизайна; для модуля со своим стилем можно всё сделать самому на Tailwind.
Диалоги `toast`, `confirm`, `prompt` удобно использовать при любом дизайне.

- `Page` — оборачивает каждую страницу. Пропсы: `title`, `subtitle`, `actions` (кнопки справа),
  `back` (`true` или путь), `width` (`"narrow" | "normal" | "wide" | "full"`).
- `Section` (`title`, `actions`), `Card` (`padding`: `"none" | "sm" | "md" | "lg"`, `interactive`, `onClick`).
- `List` + `ListItem` (`title`, `subtitle`, `left`, `right`, `onClick`).
- `Button` (`variant`: `"primary" | "secondary" | "ghost" | "danger" | "soft"`; `size`: `"sm" | "md" | "lg"`;
  `icon`, `loading`, `block`, `type`, `onClick`), `IconButton` (`label` обязателен, внутри эмодзи или svg).
- `Input`, `Textarea` — обычные пропсы input/textarea. `Select` (`options`: `string[]` или `{ value, label }[]`).
- `Field` (`label`, `hint`, `error`, внутри — поле ввода).
- `Checkbox` и `Switch` (`checked`, `onChange(boolean)`, `label`).
- `Tabs` (`tabs`: `string[]` или `{ id, label }[]`, `value`, `onChange`).
- `Modal` (`open`, `onClose`, `title`, `footer`, `size`: `"sm" | "md" | "lg"`). На телефоне выезжает снизу.
- `Badge` (`tone`: `"neutral" | "accent" | "success" | "warning" | "danger"`),
  `Stat` (`label`, `value`, `hint`, `tone`), `Progress` (`value`, `max`, `tone`).
- `EmptyState` (`icon`, `title`, `text`, `action`), `Spinner`, `Loading` (`text`).
- Графики:
  - `BarChart` (`data: { label, value, color? }[]`, `height`, `format`);
  - `LineChart` (`labels: string[]`, `series: { name, points: number[] }[]`, `format`);
  - `DonutChart` (`data`, `center`, `format`);
  - `Sparkline` (`points: number[]`);
  - `Heatmap` (`values: { "2026-09-25": 3 }`, `weeks`).
- Диалоги:
  - `toast("Сохранено", "success")`;
  - `await confirm("Удалить?", { danger: true, confirmText: "Удалить" })` → `boolean`;
  - `await prompt("Название", "")` → `string | null`.

### Утилиты

- `formatDate(d, "short" | "long" | "time" | "datetime" | "weekday")`, `formatRelative(d)` («5 минут назад»).
- `formatMoney(n, "RUB")`, `formatNumber(n, digits)`, `formatDuration(секунды)`.
- `plural(n, ["день", "дня", "дней"])`.
- `dayKey(d?)` → `"2026-09-25"`, `monthKey(d?)` → `"2026-09"`.
- `startOfDay`, `startOfWeek` (понедельник), `addDays(d, n)`.
- `uid()`, `cn(...классы)`.
- `useModule()` → `{ id, basePath, manifest }`.
- `media.microphone()`, `media.camera()` — `MediaStream`, нужны разрешения `mic`/`camera`.
  `media.notify(title, body)` — нужно разрешение `notifications`.
- `emitEvent(name, data)`, `useEvent(name, handler)` — события между модулями на странице.

## 6. Оформление — у каждого модуля свой дизайн

Хаб — нейтральная рамка: на компьютере узкая полоса с иконками модулей слева, на телефоне тонкая
полоса сверху («к хабу» + название модуля). Всё остальное — пространство модуля, и выглядеть он может
как угодно. **Не копируй внешний вид хаба**: придумай стиль под задачу модуля (тренажёр — яркий и
контрастный, дневник — спокойный и «бумажный», финансы — строгий и плотный) или следуй описанию пользователя.

Инструменты:
- **Tailwind CSS v4** — любые классы без настройки, включая произвольные значения: `bg-[#0e1a2b]`,
  `text-[#7dd3fc]`, `font-[Georgia,serif]`, `bg-gradient-to-b`, анимации.
- **Свой CSS-файл**: `import "./styles.css"`. Все классы в нём начинай с id модуля (`.water-…`), потому что
  CSS общий для страницы. Не стилизуй `html`, `body`, `*`.
- **Шрифты**: `@import url("https://fonts.googleapis.com/css2?family=…")` в начале своего CSS.
- **Своя тема**: `theme: "dark"` или `"light"` в `defineModule` — модуль всегда в этой теме, независимо от хаба.
- **Своя иконка**: эмодзи в `"icon"` или путь к картинке в папке модуля: `"icon": "icon.svg"`.
- Если у модуля свой фон — корневой элемент каждой страницы растягивай на всю высоту: `min-h-full`.

Если пользователь хочет, чтобы модуль выглядел «как хаб» и следовал его теме, используй готовые
компоненты из раздела 5 и токены темы: `bg-bg`, `bg-surface`, `bg-surface-2`, `text-fg`, `text-muted`,
`border-line`, `bg-accent text-accent-fg`, `text-success`/`text-warning`/`text-danger`
(CSS-переменные `var(--lh-bg)`, `var(--lh-fg)`, `var(--lh-accent)`…).

Правила интерфейса:
- **Сначала телефон**: ширина 360px, зоны нажатия от 40px. Для компьютера — `sm:`, `lg:`.
  Сверху на телефоне 44px занимает полоса хаба. Если указан `nav`, снизу 56px занимает меню разделов.
  Своё нижнее меню делай только без `nav`, с `padding-bottom: env(safe-area-inset-bottom)`.
- Интерфейс на русском языке (если пользователь не попросил иначе).
- Пустые состояния и загрузку показывай явно (`loading` из хуков).
- Удаление — через `confirm(...)`.
- Виджет на главной хаба — маленькая карточка (около 300×150px): только главное.

## 7. Качество кода

- TypeScript в строгом режиме: типизируй данные коллекций интерфейсами, без `any`.
- Формат данных, если он может меняться, продумывай так, чтобы старые записи продолжали работать
  (новые поля — необязательные).
- Не выдумывай функции SDK, которых нет в разделе 5.

## 8. Пример полного модуля

Модуль со своим стилем (тёмно-синяя «водная» тема на Tailwind). Данные — через SDK, диалог удаления — `confirm` хаба.

`lifehub.json`:
```json
{
  "id": "water",
  "name": "Вода",
  "version": "0.1.0",
  "description": "Сколько воды выпито за день",
  "icon": "💧",
  "type": "app",
  "sdk": "^1",
  "entry": "src/index.tsx",
  "deps": {},
  "permissions": []
}
```

`src/index.tsx`:
```tsx
import { useState } from "react";
import { defineModule, useCollection, useStore, dayKey, formatDate, confirm } from "@lifehub/sdk";

interface Drink {
  amount: number;
  date: string;
}

function useToday() {
  const drinks = useCollection<Drink>("drinks");
  const [goal, setGoal] = useStore<number>("goal", 2000);
  const today = drinks.items.filter((d) => d.date === dayKey());
  const total = today.reduce((s, d) => s + d.amount, 0);
  return { drinks, today, total, goal, setGoal };
}

/** Круг, заполняющийся водой. */
function Glass({ value, max, size = 220 }: { value: number; max: number; size?: number }) {
  const pct = Math.min(1, value / (max || 1));
  return (
    <div className="relative overflow-hidden rounded-full border-2 border-sky-300/40 bg-sky-950" style={{ width: size, height: size }}>
      <div className="absolute inset-x-0 bottom-0 bg-gradient-to-t from-sky-500 to-cyan-300 transition-all duration-700" style={{ height: `${pct * 100}%` }} />
      <div className="absolute inset-0 grid place-items-center text-center">
        <div>
          <div className="font-bold tabular-nums text-white drop-shadow" style={{ fontSize: size / 5.5 }}>{value}</div>
          {size > 120 && <div className="text-sm text-sky-100/80">из {max} мл</div>}
        </div>
      </div>
    </div>
  );
}

function Today() {
  const { drinks, today, total, goal } = useToday();
  const [custom, setCustom] = useState("");

  return (
    <div className="min-h-full bg-gradient-to-b from-slate-950 to-sky-950 px-5 py-8 text-sky-50">
      <div className="mx-auto flex max-w-md flex-col items-center">
        <Glass value={total} max={goal} />
        <div className="mt-8 grid w-full grid-cols-3 gap-3">
          {[150, 250, 500].map((ml) => (
            <button
              key={ml}
              onClick={() => drinks.add({ amount: ml, date: dayKey() })}
              className="rounded-2xl bg-sky-400/15 py-4 text-lg font-semibold text-sky-100 ring-1 ring-sky-300/30 transition active:scale-95 hover:bg-sky-400/25"
            >
              +{ml}
            </button>
          ))}
        </div>
        <form
          className="mt-3 flex w-full gap-2"
          onSubmit={(e) => {
            e.preventDefault();
            const ml = Number(custom);
            if (ml > 0) drinks.add({ amount: ml, date: dayKey() });
            setCustom("");
          }}
        >
          <input
            inputMode="numeric"
            value={custom}
            onChange={(e) => setCustom(e.target.value.replace(/\D/g, ""))}
            placeholder="Своё количество, мл"
            className="h-11 flex-1 rounded-xl bg-white/5 px-4 text-sky-50 outline-none ring-1 ring-sky-300/20 placeholder:text-sky-200/40 focus:ring-sky-300/60"
          />
          <button className="rounded-xl bg-sky-400 px-4 font-semibold text-slate-950">OK</button>
        </form>

        <ul className="mt-8 w-full space-y-1">
          {[...today].reverse().map((d) => (
            <li key={d.id} className="flex items-center justify-between rounded-xl px-3 py-2 hover:bg-white/5">
              <span className="text-sky-100">💧 {d.amount} мл</span>
              <span className="flex items-center gap-3 text-sm text-sky-200/60">
                {formatDate(d.createdAt, "time")}
                <button
                  aria-label="Удалить"
                  className="text-sky-200/40 hover:text-sky-100"
                  onClick={async () => {
                    if (await confirm("Удалить запись?", { danger: true })) await drinks.remove(d.id);
                  }}
                >
                  ✕
                </button>
              </span>
            </li>
          ))}
          {today.length === 0 && <li className="text-center text-sky-200/50">Сегодня ещё ничего — начните с утреннего стакана</li>}
        </ul>
      </div>
    </div>
  );
}

function Settings() {
  const { goal, setGoal } = useToday();
  return (
    <div className="min-h-full bg-gradient-to-b from-slate-950 to-sky-950 px-5 py-8 text-sky-50">
      <div className="mx-auto max-w-md">
        <h1 className="mb-6 text-2xl font-bold">Настройки</h1>
        <label className="block text-sm text-sky-200/70">Цель на день, мл</label>
        <input
          inputMode="numeric"
          value={goal || ""}
          onChange={(e) => setGoal(Number(e.target.value.replace(/\D/g, "")) || 0)}
          className="mt-2 h-11 w-full rounded-xl bg-white/5 px-4 text-lg outline-none ring-1 ring-sky-300/20 focus:ring-sky-300/60"
        />
      </div>
    </div>
  );
}

function Widget() {
  const { total, goal } = useToday();
  return (
    <div className="flex items-center gap-4">

}
```
