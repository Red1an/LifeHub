# DevPath

Система самообучения инженера (C#/.NET, ASP.NET Core, БД, архитектура, распределённые системы, DevOps,
алгоритмы, сети, ИИ, System Design, 1С, инженерная культура) в игровом формате.

## Заметки по модулю

- Программа — `src/data/curriculum.ts` (14 треков, 158 тем, у темы `points`). Темы можно переносить между треками — прогресс привязан к id темы, а не к треку (так net-owasp/net-api-security/net-crypto переехали в трек `sec`). id тем менять нельзя: к ним привязан прогресс.
- **Встроенные материалы** — `src/content/<трек>.md`, формат в `src/content/README.md` (теория по разделам, `---quiz`,
  `---recall`, `---task`). Разбор — `lib/content-parse.ts`, сборка урока и банка вопросов — `lib/content.ts`.
  `src/content/simple.md` — блок «Простыми словами» (аналогия) для каждой темы: встаёт первым разделом теории и шагом урока.
  `src/content/deep-<трек>.md` — слой «Глубже» (senior): разделы → `deep`, вопросы → `deepQuiz` (в тесты и тренировки,
  но не в короткий урок), recall → карточки, `---read` → «Что почитать» (Markdown-ссылки).
  Всё основное работает без нейронки; нейронка — дополнение (урок «другим взглядом», ревью, наставник, баги, вопросы).
  Проверки: `node scripts/check-content.mjs` (у каждой темы теория, «простыми словами», «Глубже», литература, ≥6 вопросов,
  нет битых вопросов) и `node scripts/check-links.mjs` (все ссылки доступны; YouTube — через oEmbed).
- **Цель и дорожная карта** — `lib/roadmap.ts`, `useStore("roadmap")`: темы выбранных треков по уровню, план по неделям
  до дедлайна, отставание и прогноз; урок дня берётся из плана (сначала долги). Страница `/goal`.
- **Видео** — `src/data/videos.ts` генерирует `node scripts/fetch-videos.mjs [id…]` (поиск YouTube, ранжирование,
  проверка встраивания). Запросы, доверенные каналы, PINNED/BANNED — в самом скрипте. Файл не править руками.
- Словарь терминов — `src/data/glossary.ts`: в теории и шагах-объяснениях (`<Md terms />`) первое упоминание термина
  подчёркивается, по нажатию — определение. «*» в конце — основа слова. Не добавлять короткие многозначные слова.
- Проекты по этапам — `src/data/projects.ts`, прогресс в коллекции `projects` (id проекта).
- Стартовые карточки — `src/data/cards.ts` (id `seed-<индекс>`, новые только в конец) + recall-вопросы темы (id `rc…`),
  добавляются в колоду при старте темы (`startTopic`).
- Коллекции: `topics` (статус, освоение, урок от ИИ, `builtinStep`/`lessonStep`, `testBest`, заметки), `cards` (SM-2,
  `lib/srs.ts`), `log` (всё, за что дан опыт — XP, серия, тепловая карта, достижения), `days` (план дня, id = dayKey),
  `mistakes` (работа над ошибками, id — хэш вопроса; исправлено после 2 верных подряд), `watched` (видео),
  `projects`, `practice`, `chats`. Настройки — `useStore("settings")`, звук — `useStore("sound")`.
- Опыт начисляется только через `award()` из `lib/store.ts` — она же отмечает квест дня. Ответы на вопросы записываются
  в `mistakes` автоматически в `StepPlayer` (`recordAnswer`).
- Шаги уроков `Step` (`lib/types.ts`): explain / choice / order / bug / open / recall. Играются в `components/StepPlayer.tsx`;
  варианты choice перемешиваются при показе (в материалах верный ответ часто вторым — это нормально).
- План дня (`lib/daily.ts`) построен по науке об обучении: повторение → новый урок → видео → вспоминание
  (ошибки / смешанная / тест) → практика; нейронка — не каждый день.
- Свой тёмный «игровой» стиль: классы `dp-*` в `src/styles.css`, цвета — CSS-переменные `--dp-*`.
