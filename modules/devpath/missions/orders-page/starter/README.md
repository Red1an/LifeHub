# Страница заказов тормозит

Условие, подсказки и разбор — в DevPath (Мастерская). Здесь только код.

- Код — `src/Orders/OrdersPage.cs` (модель и `DbContext` — `src/Orders/ShopDb.cs`).
- Тесты — `tests/`. Их кладёт хаб и обновляет перед каждой проверкой. База — SQLite в памяти, тесты считают SQL-запросы.
- Проверить: кнопка «Проверить» в DevPath или `dotnet test` в этой папке.
