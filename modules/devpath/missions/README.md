# Миссии и каты Мастерской

Миссия — настоящий маленький проект с проблемой. Ученик получает его в `~/DevPath/<id>`, правит в своей IDE,
а хаб проверяет тестами (`server/devpath`). Ката — короткая задача, код пишется прямо в редакторе модуля.

## Миссия: `missions/<id>/`

```
mission.md      — текст (формат ниже); импортируется в src/data/workshop.ts
starter/        — что получает ученик: Mission.slnx, src/…, README.md. Копируется один раз, дальше папка его
tests/          — тесты хаба (xUnit). Перед каждой проверкой кладутся в <папка>/tests заново
solution/       — эталон: файлы поверх starter, с которыми проходят все тесты
```

Правила:
- заготовка **собирается**, но тесты не проходят: недописанное — через `throw new NotImplementedException()`;
- имена тестов — `DisplayName` по-русски, с номером: «1. Что проверяется» — ученик видит их как чек-лист;
- тест на скорость — с прогревом и запасом по времени в 3–5 раз, `DisableTestParallelization`;
- пакеты — версии из уже используемых (xunit 2.9.3, Microsoft.NET.Test.Sdk 17.14.1, xunit.runner.visualstudio 3.1.4,
  Mvc.Testing 10.0.0, EF Core Sqlite 10.0.5), чтобы не качать лишнего.

Проверка: `node server/devpath/verify.ts [id…]` из корня хаба — заготовка красная, эталон зелёный.

### mission.md

```
---
title: Отчёт строится 40 секунд
icon: 🐢
level: 1                     ← 1 Junior, 2 Middle, 3 Senior
kind: speed                  ← fix (почини) | build (допиши) | speed (ускорь)
topics: csharp-collections   ← id тем из src/data/curriculum.ts, первая — главная
minutes: 30
skills: что прокачивает, одной строкой
---
Ситуация: что случилось, как в жизни (жалоба, инцидент, метрика). Без подсказок к решению.

---task
Что сделать: требования, которые проверяют тесты.

---primer Заголовок
«Минимум, чтобы начать» — разобранный пример на ДРУГОМ коде (не решение миссии).

---hypothesis
Вопрос, на который ученик отвечает до начала работы.

---hint
1-я ступень: наводящий вопрос.
---hint
2-я: направление.
---hint
3-я: почти решение, но без готового кода.

---debrief
## Почему так            ← разделы разбора: причина, альтернативы, когда решение плохое, как в продакшене
…

---quiz                  ← вопросы «почему» в формате src/content/README.md
? …

---recall                ← в карточки повторения после миссии
Q: …
A: …
```

## Ката: `katas/<id>/`

`kata.md` + `Tests.cs`. Код ученика целиком становится `Solution.cs` рядом с тестами (общий проект `~/DevPath/.kata`).

```
---
title: …
level: 1
topics: …
minutes: 15
---
Условие с примером.

---starter
```csharp
public static class Kata { … throw new NotImplementedException(); }
```

---why
Идея, сложность, альтернативы, типичные ошибки.

---solution
```csharp
эталон
```
```

Новую миссию или кату добавь в `src/data/workshop.ts` — там же порядок прохождения.
