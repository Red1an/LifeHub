# Отчёт строится 40 секунд

Условие, подсказки и разбор — в DevPath (Мастерская). Здесь только код.

- Код — `src/Report/SalesReport.cs`.

- Проверить: кнопка «Проверить» в DevPath или `dotnet test` в этой папке.
