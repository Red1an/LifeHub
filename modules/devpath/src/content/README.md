# Формат учебных материалов

Один файл — один трек. Тема начинается строкой `# @<id темы>` (id из `src/data/curriculum.ts`).

```
# @csharp-async

## Заголовок раздела          ← раздел теории = шаг-объяснение в уроке
Markdown, код в ```csharp …```.

---quiz                       ← вопросы; каждый начинается с «? »
? Что выведет программа?
```csharp
Console.WriteLine(1);
```
- [ ] неверный вариант
- [x] верный вариант
> Объяснение (строки с «> »).

? Расставь по порядку          ← нумерованный список в правильном порядке
1. первое
2. второе
> Почему так.

? Найди баг: что делает код    ← блок кода с bug=<номер строки, с 1>
```csharp bug=2
var a = 1;
var b = a / 0;
```
```fix
var b = a / 1;
```
> В чём ошибка.

---recall                     ← самопроверка по памяти, пары Q:/A:
Q: Вопрос?
A: Ответ.

---task Название задачи       ← практика без нейронки
Условие в Markdown.
- [ ] критерий самопроверки
```
