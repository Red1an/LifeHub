# Инвестиции

Все счета Т-Банка (брокерские, ИИС) и БКС в одном портфеле: доход и дивиденды, прогноз, разбор портфеля и прошлых
сделок, идеи, куда вложить. Перенос macOS-приложения InvestFinance (Swift) с доработками.

## Заметки по модулю

- **Данные** (`lib/store.tsx`, ключи `useStore`): `portfolio` (Portfolio: счета, бумаги, операции, позиции, выплаты),
  `market` (недельные цены и индексы, ключевая ставка — отдельно, т.к. большие), `settings`, `snapshots`, `screener`,
  `bonds`, `visit`, `log`. Коллекция `reviews` — сохранённые ответы нейронки. Даты — ISO-строки, цены — `[день, цена]`.
  Старые сохранённые данные дополняются значениями по умолчанию (`{ ...emptyPortfolio(), ...stored }`).
- **Расчёт** — чистые функции, всё пересчитывается в `InvestProvider` (layout модуля):
  `analytics.ts` (позиции по средней цене, XIRR, TWR, прогноз выплат на 2 года, структура, риск, «те же деньги в индекс»),
  `income.ts` (доход на руки, прогноз на след. год с бэктестом, «почему изменился», цель), `health.ts` (проверки
  «что не так» с оценкой 0–100, классы активов и ориентир под профиль риска), `mistakes.ts` (разбор сделок задним
  числом), `ideas.ts` (распределение суммы по классам + кандидаты; контекст для нейронки).
- **Синхронизация** (`sync.ts`) идёт в браузере, запросы — через `net` хаба (разрешение `network`). API Т-Банка
  подписан НУЦ Минцифры: хаб доверяет этому корню сам, заголовок `authorization` пропускается.
  Состояние «идёт обновление» — в модуле (`useRun`), а не в компоненте. Ключи бумаг приводятся к ISIN через MOEX
  (`normalizeInstruments` → `rekey`), так одна бумага у разных брокеров склеивается.
- **БКС** присылает новый refresh-токен при каждом обмене — сохраняем, чтобы 90-дневный срок продлевался.
  Неторговые операции БКС разбираются эвристически (схема не опубликована).
- **Дивиденды**: с токеном Т-Банка — `GetDividends`; без него — приблизительный справочник `reference.ts`
  (MOEX ISS дивиденды сейчас не отдаёт). Подбор акций помечает источник.
- **Идеи**: обычные и привилегированные акции — одна компания (`issuer` в `ideas.ts`); компании с долей больше 10 %
  не предлагаются; лоты подбираются в пределах суммы.
- **«Что делать»** (`actions.ts`): все находки в один список с приоритетом 1–3. id действия стабилен
  (без чисел, которые меняются), отметки «сделано» — ключ `done`. Источники: проверки `health.ts`, вердикты `advice.ts`
  (только «Проверить»), налоги `tax.ts`, подушка (ключ `assets` + `settings.monthlyExpenses`), отсечки, список наблюдения.
- **Связь с «Финансами»** (`lib/finance.ts`, разрешение `read:finance`): ключ `summary` модуля finance — средние траты
  в месяц по реальным операциям, остатки на картах и накопительных, долги по кредиткам и сплитам. Если сводка есть и
  `settings.savingsSource !== "manual"`, `settings.monthlyExpenses` в расчётах — из неё (вписанное вручную хранится
  и показывается при ручном режиме — `manualExpenses`), счета «Финансов» добавляются к сбережениям (`otherAll`,
  `fromFinance: true`, только чтение), долги вычитаются из подушки. Формат чужой — читаем, допуская отсутствие полей.
- **Вердикт по бумаге** (`advice.ts`): докупать / держать / не докупать / сократить / проверить + оценка 0–5 по
  направлениям. Обычка и префы — одна компания. Корпоративные облигации с премией к ОФЗ > 6 п.п. — «Проверить».
- **Облигации** (`bonds.ts`, страница `Bonds.tsx`): лесенка ОФЗ с фиксированным купоном до срока, когда нужны деньги;
  в режиме «больше дохода» до 40 % — облигации крупных эмитентов (список `RELIABLE`) с премией ≤ 2,5 п.п.
  Тип купона берётся из `BONDTYPE` MOEX: флоатеры и линкеры в лесенку не попадают. Данные (`bonds`) обновляются
  при каждом обновлении рынка.
- **Из аналогов** (Snowball, Sharesight, Simply Wall St): сбережения вне брокеров и подушка, налоги года,
  оценка бумаги по направлениям, список наблюдения (`watchlist`), итоги месяца (`monthly.ts`).
- **Заработок по бумагам** (`perf.ts`, вкладка «Заработок» и блок на карточке бумаги): итог = стоимость в конце −
  в начале − (купил − продал) + выплаты. Процент — к средней вложенной в бумагу сумме, пока она была в портфеле
  (время-взвешенная себестоимость), итог по портфелю — к средней стоимости портфеля за период. Комиссии за
  обслуживание и налог с продаж к бумагам не относятся — поэтому сумма по бумагам чуть больше общей прибыли.
- **Демо** (`demo.ts`) строится по реальным недельным ценам MOEX; в нём специально есть продажи — для разбора ошибок.
  Демо удаляется при первой синхронизации реальных счетов.
- **Цвета**: получено — золотой сплошной, ожидается/объявлено — бледный, прогноз — серый штрих. Рост — зелёный,
  падение — красный, стоимость — синий. Классы `inv-*` в `styles.css`, шрифт Manrope, тема тёмная.
- Тексты для людей без жаргона; у карточек кнопка «?» с объяснением. Нейронка получает только сводку (без токенов и операций).
