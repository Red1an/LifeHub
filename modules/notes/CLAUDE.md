# Заметки

Воронка для мыслей: быстро кидаешь текстом, голосом, фото, через «Поделиться» или из виджета → нейронка предлагает
разбор (склеить обрывки или разделить список, определить тип и его поля, контекст, проект/сферу, связи, события и
сроки) → одно подтверждение. Плюс подборки «что делать дальше», очередь с оценками, проекты и сферы с историей,
чат по заметкам, граф связей, обзор забытого.

Откуда идеи: кит «AI как бизнес-партнёр» (Stachka 2026) — инбокс отдельно от фактов, единый план, вопросы вместо
догадок, два слоя у темы; Capacities/Tana — типы с полями; PARA — проекты и сферы; Letterboxd/Goodreads — «готово»
с оценкой; Things/GTD — контексты и «отложить»; Mymind/Readwise — захват отовсюду; Mem/Reflect — «спросить заметки».

## Заметки по модулю

- **Данные** (`src/lib/types.ts`). Коллекция `notes` открыта другим модулям — поля только добавлять.
  1.x: `{ title, body, tags, pinned }` (status нет → разобрана). 2.0: `shelf` (полка). 2.1: `kind` + `props`.
  Тип всегда через `kindOf()` из `lib/kinds.ts` — он понимает все три формата. Сброс поля — `null`
  (undefined в JSON пропадает, PATCH сливает поля).
  `topics` — слой «что сейчас» (`summary` переписывается) + `kind: project | area` (нет поля = сфера), `goal`, `due`,
  `closedAt`. `topic_log` — история темы, только дописывается.
- **Три оси раскладки** (2.4, `lib/kinds.ts`), все проставляет нейронка:
  1. **Тип** (`KINDS`, сгруппированы в `GROUPS` по действию: Досуг / Сделать / Попробовать / Знать / Люди / Моё);
  2. **Сфера** (`AREAS`, 8 постоянных по «колесу жизни»; переименования — `useStore("areas")`, хук `useAreas`).
     Поле `area` у каждой заметки и у проекта. Без сферы — кнопка «Разложить по сферам» (`lib/areas.ts`);
  3. **Когда** (`CONTEXTS`).
  Темы теперь только **проекты** (PARA) внутри сфер; старые темы `kind: "area"` показываются как «Другие темы».
  «Что дальше» на полках — `COLLECTIONS` в `pages/Shelves.tsx`, страница сферы — `/area/:id`.
- **На заметку** (kind `ref`, 2.5): справка «на всякий случай» — лекарства, бренды, программы, каналы, факты.
  Пользователь часто записывает просто название без действия — это не `buy`: в промпте `buy` только при явном «купить».
- **Слова** (kind `word`, `pages/Words.tsx`): значение и пример нейронка берёт из общих знаний; повторение
  карточками, `srs: { step, due }`, интервалы `SRS_STEPS` (1, 3, 7, 14, 30, 90 дней), забыл — снова завтра,
  прошёл все — `done` («выучил»). Первый повтор — завтра после разбора.
- **Типы** — `KINDS` в `lib/kinds.ts`: поля (`fields`, их `hint` уходит в промпт), `queue` — глагол «готово»,
  `rate` — спрашивать оценку. Контексты — `CONTEXTS`. Подборки на «Полках» — `COLLECTIONS` в `pages/Shelves.tsx`.
- **Жизненный цикл**: в очереди → `done` + `doneAt` (+ `rating`, `verdict` через `useDone()`) → `status: "archived"`.
  `snoozeUntil` прячет с полок до даты, потом заметка всплывает в «Обзоре» («Понял» сбрасывает поле).
- **Разбор** (`lib/triage.ts`): ссылки → `net.fetch` + `DOMParser` (og:*) → `lib/links.ts`; до 5 фото уходят в
  `ai.json` как `images` (быстрая модель с фото заменяется основной); кандидаты в связи — `similar()` из
  `lib/related.ts`. Одна запись может дать несколько заметок (список «посмотреть: А, Б»): первая берёт id записи,
  остальные создаются. План — `useStore("triage")`; план старого формата (без `kind`) отбрасывается `isCurrentPlan`.
- **«Поделиться»**: в манифесте `"share": "/"` — хаб (PWA share_target → `/share`) открывает воронку с
  `?title&text&url`; `Inbox.tsx` кладёт в воронку и чистит параметры (`shared` — защита от двойного эффекта).
- **«Спросить»** (`lib/ask.ts`, `pages/Ask.tsx`): контекст — похожие + заметки темы, названной в вопросе, + свежие
  (до 80); ответ стримится, ссылки `[[id]]` → чипы. Разговор — `useStore("chat")`.
- **Расписание** — сами в Google не пишем: события и дела со сроком уходят ссылкой `~/m/planner/ask?text=…`
  (`useSendToCalendar`, `useSendDeadline`), «Расписание» подставляет текст. Отметки `event.sentAt`, `dueSentAt`.
  «Финансы» у пользователя выключены — покупки туда не передаём.
- **Дневник** (kind `day`, `pages/Days.tsx`): длинный рассказ о дне сохраняется целиком заметкой `day` (`dayDate`,
  `props.mood/highlight`), дела, события, фильмы и т. п. из него — отдельными заметками с `fromDay` = id записи дня.
  Если нейронка разрезала длинную запись (≥ 280 символов, ≥ 2 заметки), но не сделала `day`, — `linkDays` в
  `lib/triage.ts` сохраняет исходник сам. Записи дня в плане идут первыми, чтобы забрать id записи воронки.
- **Дубли** (`findDupes` в `lib/triage.ts`): та же ссылка (без utm и т. п., `normUrl`) или то же название → в промпт с
  пометкой «⚠ возможно, то же самое», нейронка ставит `mergeInto`; та же ссылка без ответа нейронки — дубль и так
  (`urlDupe`). Применение дописывает в прошлую заметку «— дата: текст», объединяет ссылки, фото, теги, контексты и
  возвращает её из архива/отложенного.
- **Отмена разбора**: `applyItems` пишет через `Tracker` — перед первой записью в документ запоминает, каким он был
  (`null` — создан разбором). Снимок — `useStore("undo")`, кнопка «Отменить» в воронке сутки; `undoTriage` делает
  `put` прежних версий и удаляет созданное.
- **Обложки** (`lib/enrich.ts`): фильмы — Википедия (статья должна называться так же, иначе находит актёров;
  постеры там несвободные и через API почти не приходят — обычно только описание), книги — Open Library (обложка +
  рейтинг) + описание из Википедии без экранизаций, приложения — поиск App Store. После разбора — в фоне
  (`enrichMany`), в заметке — кнопка «Найти обложку» и «Убрать — не то». `enrichedAt` — уже искали.
- **[[Ссылки]]** (`lib/wikilinks.ts`): в просмотре `[[Название]]` → `#nt:<id>` или `#nt-new:<название>` (нажатие
  создаёт заметку), перехват кликов в `Rendered`. «Ссылаются сюда» — `backlinks`. Подсказка после `[[` в редакторе.
  Ссылки — тоже рёбра графа (`wikiEdges`).
- **«Найти связи»** (`lib/linker.ts`, кнопка на графе): нейронка смотрит последние 160 заметок и предлагает пары
  с «почему»; пользователь отмечает, какие связать.
- **Без связи** (`lib/outbox.ts`): очередь в `localStorage["lifehub-outbox"]` — общая со страницей «Хаб недоступен»
  (OFFLINE_HTML в `server/app.ts`, там поле «Записать мысль»). Воронка отправляет её при открытии, по `online` и раз
  в 30 с; неудачная запись из поля воронки тоже уходит в очередь. Это единственное место с localStorage — очередь
  на отправку, не хранилище.
- **Проверяя на живом хабе**, не очищай коллекции целиком — там данные пользователя; удаляй свои тестовые записи по id.
- **Обзор** (`lib/review.ts`): локальные правила сразу; находки нейронки — по кнопке, кэш `useStore("review")`.
- **Граф** — своя силовая раскладка (`lib/graph.ts`), минимальная область 360, чтобы пара узлов не была гигантской.
- **Голос** — копия `useDictation` из planner (`components/input.tsx`); правишь там — перенеси сюда.
- **Стиль** — тёплая бумага, классы `nt-*` в `src/styles.css`, Lora + Golos Text, тема следует хабу. Модалки
  рендерятся в body — внутри оборачивать в `nt-root`. Липкие панели снизу — `bottom-[68px] sm:bottom-3`
  (на телефоне снизу меню хаба).
- Эффекты — всегда с фигурными скобками: `scrollIntoView` в новых браузерах возвращает Promise, и React падает,
  приняв его за функцию очистки.
