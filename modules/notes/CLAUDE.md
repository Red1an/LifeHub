# Заметки

Заметки в markdown: список с поиском и тегами, редактор с предпросмотром, закреплённые заметки.

## Заметки по модулю

- Коллекция `notes`: `{ title, body, tags: string[], pinned: boolean }`. Открыта другим модулям на чтение.
- Markdown рендерится пакетом `marked` (из общего кэша хаба).
