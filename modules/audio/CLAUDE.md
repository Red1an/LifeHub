# Аудио (библиотека)

Общий аудиодвижок, вынесенный из GuitarHub. Им пользуются модули guitar и любые будущие
(тренер речи, вокал). Код загружается в браузер один раз, поэтому AudioContext один на всю страницу.

## Заметки по модулю

- `getAudioContext()` — единственный AudioContext; не создавай свои.
- `openMic()` / `startPitchTracking()` — микрофон и высота тона. Поток микрофона общий на страницу (счётчик
  пользователей, закрывается через 4 с после последнего) — переходы между упражнениями не мигают микрофоном.
- `detectPitch` — метод МакЛеода (NSDF через БПФ, окно до 4096): дёшево и без октавных ошибок.
- `PitchStabilizer` — то, что видит пользователь: шумовой порог по комнате, медиана кадров, гистерезис смены ноты,
  отбрасывание октавных скачков, удержание ноты 350 мс. `useMicPitch` использует его (`mode: "fast"` для бендов/вибрато),
  `onFrame` по-прежнему получает сырые кадры для анализа.
- Хуки: `useMicPitch`, `useMicSource`, `useOnsetRecorder`, `useHoldTimer`.
- Калибровка задержки (`getLatencyMs`/`setLatencyMs`) хранится в localStorage намеренно:
  она своя у каждого устройства (у телефона и компьютера разная задержка).
- Меняешь API несовместимо — повышай мажорную версию в lifehub.json.
