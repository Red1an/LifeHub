# Расписание

Ставит события в Google Календарь по просьбам текстом, по фото (расписание пар, афиша, скриншот переписки)
и по данным других модулей (Форма, DevPath, Привычки). Перед записью всегда показывает черновик.

## Заметки по модулю

- **Google** — через `google.calendar()` SDK (разрешение `google:calendar`). Аккаунт подключается в настройках хаба,
  токен модулю не виден. Обёртки над API — `src/lib/gcal.ts`. После любых изменений вызывать `eventsChanged()` —
  страницы перечитают события.
- **Свои события** помечаются `extendedProperties.private.lifehub = "planner"` (+ `category`, `source`). Нейронка может
  менять и удалять **только** их (`normalize` в `lib/planner.ts` отбрасывает остальные). Чужие события — только
  занятое время.
- **Целевой календарь** — `prefs.calendarId` (по умолчанию предлагается создать отдельный «LifeHub»).
  `prefs.readCalendars` пусто → показываем календари, видимые в Google (`selected`).
- **Нейронка** (`lib/planner.ts`): `ai.json` с картинками (`images` — id файлов модуля). В запрос идут: текущая дата и
  ближайшие дни с днями недели (иначе путает «в пятницу»), настройки дня, занятость на `prefs.horizon` дней, события
  LifeHub с id, тексты источников. Ответ — `{summary, questions, events[]}` → `Draft[]`. Повторы — одно событие с
  `recurrence` (RRULE собирается в `gcal.ts`). Уточнение черновика — тот же запрос + текущий черновик + просьба.
- **Черновик** — `useStore("plan")` (переживает перезагрузку и виден с телефона). Применение — по одному событию;
  неудавшиеся остаются в черновике. Итог — коллекция `history`.
- **Источники** (`lib/sources.ts`): `kv.get("profile", …, { from: "fit" })`, `roadmap` + коллекция `days` из devpath,
  коллекция `habits`. Владельцы открывают их в `exports`. Чужие данные читаются поле за полем — формат может меняться.
  Новый источник: добавить в `SOURCES`, разрешение `read:<id>` сюда и `exports` в модуль-владелец.
- **Голосовой ввод** — `useDictation` в `components/input.tsx`: распознавание речи браузера (Web Speech API, `ru-RU`).
  Работает в Chrome/Edge/Safari и только в защищённом контексте (localhost или HTTPS через Tailscale/ngrok);
  по http в локальной сети браузер его не даёт — показываем подсказку. Поля ввода растут с текстом (`AutoTextarea`).
- Фото запроса загружаются в файлы модуля (разрешение `files`) — так нейронка получает их по id и они видны в истории.
- Стиль: тёмный «ночной» (`theme: "dark"`), классы `pl-*` в `src/styles.css`, шрифт Onest, градиент фиолетовый → розовый.
  Цвета категорий — `CATEGORIES` в `lib/types.ts` (там же `colorId` Google).
