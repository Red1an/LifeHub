# Форма

Тренировки под место и инвентарь (дом, площадка с турником, мини-зал со штангой и гантелями, офис),
постепенное усложнение, техника упражнений, разминки у рабочего стола, зарядка, растяжка и тренер-нейронка.

## Заметки по модулю

- **Библиотека** — `src/data/strength.ts` (силовые, кардио, гантели, штанга, резинка), `src/data/mobility.ts`
  (суставная разминка, у стола, растяжка) и `src/data/standing.ts` (гимнастика стоя для зарядки). У упражнения: паттерн,
  мышцы, инвентарь, сложность 1–10, `chain`, техника (steps/cues/mistakes/breathe), `say` (фраза для голоса), `avoid`
  (колени/поясница/плечи/запястья), теги. **id не менять** — к ним привязаны история, рекорды и ступени.
  Видео — ссылка на поиск YouTube (`videoUrl`). `EXERCISES` — только свои: на них работают генератор, лестницы и тренер.
- **Расширенный каталог** — `src/data/extra.ts`: ~850 упражнений из free-exercise-db (Unlicense), сгенерирован скриптом,
  id вида `x:<папка>`. Названия переведены, техники нет — `lib/media.ts` грузит английскую с jsDelivr и один раз
  переводит нейронкой (`ai.json`, модель fast) в коллекцию `howto` (id = папка). `CATALOG` и `EX` — свои + каталог.
- **Наглядность** (`components/Visual.tsx`), источники по порядку: короткий ролик YouTube (`yt`, встраивание без звука
  по кругу), GIF-анимация ExerciseDB (`gif`, static.exercisedb.dev), схема-человечек (`components/Figure.tsx`, позы в
  `ANIMS`), два кадра free-exercise-db (`photo`). Если источников несколько — переключатель, выбор помнится в
  localStorage. Карты id → ролик/GIF — `data/demos.ts` (собраны поиском, промахи убраны руками; правь там же).
- **Лестницы навыков** (`CHAINS` в `data/library.ts`) — упражнения одной `chain`, упорядоченные по `level`.
  Текущая ступень — `useStore("levels")`: chain → id. Ступень засчитывается в `levelUps()` (`lib/game.ts`): все подходы
  на верхней границе повторов (или удержание `masterySec`) и оценка не «тяжело». На месте без нужного инвентаря
  берётся ближайшая доступная ступень ниже (`chainStep`).
- **Генератор** (`lib/generator.ts`): слоты по фокусу (full/upper/lower/push/pull/core/hiit/mobility), оценка кандидатов
  (приоритет паттерна, вес при цели «сила/мышцы», восстановление мышц, разнообразие), бюджет времени, разминка под
  сегодняшние паттерны, заминка под работавшие мышцы. `prescribe()` — подходы/повторы/отдых по цели и двойная
  прогрессия по прошлому разу (вес +шаг, если все подходы на максимум; −10%, если провал и «тяжело»).
- **Умный выбор** (`autoFocus`): сплит по числу тренировок в неделю (≤3 — всё тело, 4 — верх/низ, 5+ — жимы/тяги/ноги),
  из него — фокус с самыми восстановленными мышцами. Восстановление — `recovery()` (усталость за 72 часа).
- **Плеер** (`pages/Player.tsx`, `lib/session.ts`): тренировка разворачивается в шаги work/rest. Разминка, заминка,
  готовые комплексы и круговые идут сами по таймеру; основные подходы — ввод повторов/веса или «Старт» для удержаний.
  Незаконченная тренировка — `useStore("active")` (переживает перезагрузку). Голос — speechSynthesis, звук — WebAudio.
- Коллекции: `workouts` (все занятия: kind workout/break/morning/stretch, items с планом и фактом, xp, prs, ups),
  `tests` (тесты силы), `body` (вес, id = день). Store: `profile`, `levels`, `hidden`, `active`, `buildOpts`, `draft`
  (черновик пересобирается каждый день и при смене параметров), `coachPlan`, `coachChat`.
- Готовые комплексы (у стола, зарядка, растяжка) — `data/routines.ts`, формат `[id, секунд, повторов?]`. Зарядки —
  только стоя, без пола. **Зарядка дня** — `data/morning.ts`: блоки сверху вниз (шея → руки → корпус → ноги → разогрев →
  сила → дыхание), выбор по seed = дата (+ «другая»), длина 5/10/15 в store `morningOpts`.
- **Свои комплексы** — коллекция `mine` (`lib/custom.ts`, `pages/MyRoutine.tsx`): зарядка/разминка/растяжка идут по
  таймеру (круги и отдых → `circuit`), «тренировка» — подходы и повторы через `makeItem`. Каталог с фильтрами по мышцам,
  типу и инвентарю — `pages/Catalog.tsx` (`CatalogList` переиспользуется в окне выбора).
- **Голос** — `lib/sfx.ts`: выбирает лучший русский голос (Natural/Online/Google), можно выбрать в настройках
  (`voiceName`, `voiceRate`). Перед упражнением плеер говорит название и `say` (или первые шаги техники).
- Опыт, ранги, серии (недельная — по цели тренировок, дневная — любое движение), достижения — `lib/game.ts`.
- Напоминание размяться — в `Layout` и виджете, пока хаб открыт (разрешение `notifications`).
- Нейронка (разрешение `ai`) — только дополнение: `pages/Coach.tsx` собирает тренировку из id каталога (`ai.json`)
  и отвечает на вопросы. Всё остальное работает без неё.
- Свой тёмный спортивный стиль: классы `ft-*` в `src/styles.css`, цвета — `--ft-*` (лайм, оранжевый, циан),
  шрифты Unbounded (заголовки, цифры) и Manrope.
