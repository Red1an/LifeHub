# Гитара

Любая песня — аккорды и табы из поиска, лучший видеоразбор, упражнения под песню; пути обучения (подбор на слух,
импровизация, ритм, баррэ, перебор, вокал), справочник аккордов, 25 тренажёров с микрофоном, прогресс и план дня.

## Заметки по модулю

- Структура как у остальных модулей: `pages/` (страницы), `pages/train/` (тренажёры), `components/` (`kit.tsx` —
  общий набор), `lib/`, `data/`. Маршруты — в `src/index.tsx`. Старые ссылки `/songs/<slug>` и `/practice` перенаправляются.
- Свой тёмный стиль «вечерняя сцена»: классы `gt-*` в `src/styles.css`, цвета `--gt-*` (латунь, медь, зелёный «в ноту»),
  шрифты Oswald (заголовки), Golos Text, JetBrains Mono (текст песен и табы — важна моноширинность и кириллица).
  Старые страницы тренажёров на zinc/emerald подстраиваются переопределениями в конце `styles.css`.
- **Тренажёры**: `data/exercises.ts` — у каждого цель, шаги, ошибки и тема видео. `components/train/ExerciseShell.tsx`
  сам находит упражнение по адресу и показывает блок «Как заниматься» (открыт при первом заходе, `useStore("guidesSeen")`).
  Новый тренажёр = страница в `pages/train/` + запись в `EXERCISES` + строка в `routes`.
- **Песни** (`lib/songs.ts`): встроенные — `data/songs.ts` (id `s-<slug>`), свои и сохранённые — коллекция `songs`
  (свои `u-…`, с Ultimate Guitar `ug-<номер>`). Всё личное о песне — коллекция `songMeta` с тем же id: статус, избранное,
  транспонирование/капо/шрифт, чек-лист, найденные видео, `src` (полный адрес версии UG). Старые kv-ключи
  `guitarhub_user-songs`/`guitarhub_favorites` переносятся один раз (`migrateOldSongs`).
- **Поиск аккордов и табов** — `lib/ug.ts`: страницы Ultimate Guitar через `net` хаба (разрешение `network`), JSON из
  `div.js-store`. Платные версии отбрасываются. Короткий адрес `/tab/<id>` работает не у всех версий — передаём полный
  (`/song/ug-<id>?u=<url>`, потом берётся из `songMeta.src`). Аппликатуры UG — струны от 1-й, лады абсолютные.
- **Текст песни** — `lib/sheet.ts`: одна модель для UG (`[ch]`, `[tab]`), своего ChordPro-lite (`[G]слова`, `[[Припев]]`)
  и вставленного текста (строки из аккордов над словами, табы `e|---`). Аккорды хранятся с колонкой → транспонирование и
  перенос строк под ширину экрана (`wrapPair`, табы — по тактам `wrapTab`). Рисует `components/Sheet.tsx`.
- **Аккорды** — `lib/chords.ts`: разбор любого обозначения (H = B, слэш-аккорды, sus/add/dim/m7b5…), поиск аппликатур по
  грифу с пальцами и баррэ (`voicings`), канонические формы в `STANDARD` всегда первые, обратная задача `identify`.
  `resolveChordShape` (старые тренажёры) = `bestShape`.
- **Видео**: уроки к темам — `data/videos.ts`, генерирует `node scripts/fetch-videos.mjs [тема…]` (поиск YouTube,
  ранжирование, проверка встраивания; при ограничениях YouTube ждёт и не затирает найденное). Руками файл не править.
  Разборы конкретной песни и оригинал ищутся на лету (`lib/youtube.ts`) и сохраняются в `songMeta`.
- **Учёба** — `data/paths.ts`: пути из шагов lesson/video/exercise/practice/song, прогресс — коллекция `learn`
  (id шага). id шагов не менять.
- Тренажёры «Смена аккордов» (`?chords=`) и «Джем» (`?chords=&key=`) принимают аккорды песни.
- Звук, микрофон, высота тона — библиотека `audio` (`@modules/audio`); там же стабилизатор показаний. Гитарный синтез и
  аккомпанемент (`lib/audio/guitar-synth.ts`, `backing.ts`) — здесь.
- Прогресс тренажёров и дни занятий — по-прежнему kv через `lib/storage.ts` (`guitarhub_train-stats`,
  `guitarhub_practice-days`, `guitarhub_breath-log`). Записи голоса — файлы хаба + коллекция `recordings`.
