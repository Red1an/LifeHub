# Гитара

Любая песня — аккорды и табы из поиска, лучший видеоразбор, упражнения под песню; пути обучения (подбор на слух,
импровизация, ритм, баррэ, перебор, вокал), справочник аккордов, 25 тренажёров с микрофоном, прогресс и план дня.

## Заметки по модулю

- Структура как у остальных модулей: `pages/` (страницы), `pages/train/` (тренажёры), `components/` (`kit.tsx` —
  общий набор), `lib/`, `data/`. Маршруты — в `src/index.tsx`. Старые ссылки `/songs/<slug>` и `/practice` перенаправляются.
- Свой тёмный стиль «вечерняя сцена»: классы `gt-*` в `src/styles.css`, цвета `--gt-*` (латунь, медь, зелёный «в ноту»),
  шрифты Oswald (заголовки), Golos Text, JetBrains Mono (текст песен и табы — важна моноширинность и кириллица).
  Старые страницы тренажёров на zinc/emerald подстраиваются переопределениями в конце `styles.css`.
- **Тренажёры**: `data/exercises.ts` — у каждого цель, шаги, ошибки и тема видео. `components/train/ExerciseShell.tsx`
  сам находит упражнение по адресу и показывает блок «Как заниматься» (открыт при первом заходе, `useStore("guidesSeen")`).
  Новый тренажёр = страница в `pages/train/` + запись в `EXERCISES` + строка в `routes`.
- **Песни** (`lib/songs.ts`): встроенные — `data/songs.ts` (id `s-<slug>`), свои и сохранённые — коллекция `songs`
  (свои `u-…`, с Ultimate Guitar `ug-<номер>`). Всё личное о песне — коллекция `songMeta` с тем же id: статус, избранное,
  транспонирование/капо/шрифт, чек-лист, найденные видео, `src` (полный адрес версии UG). Старые kv-ключи
  `guitarhub_user-songs`/`guitarhub_favorites` переносятся один раз (`migrateOldSongs`).
- **Поиск аккордов и табов** — `lib/ug.ts`: страницы Ultimate Guitar через `net` хаба (разрешение `network`), JSON из
  `div.js-store`. Платные версии отбрасываются; 404 на поиске — это «ничего не найдено». Поиск идёт параллельно и на Songsterr: песни,
  которых нет на UG, открываются как `/song/sst-<songId>` (только табы партий, сразу вкладка «Табы»). Короткий адрес `/tab/<id>` работает не у всех версий — передаём полный
  (`/song/ug-<id>?u=<url>`, потом берётся из `songMeta.src`). Аппликатуры UG — струны от 1-й, лады абсолютные.
- **Табы партий** — `lib/songsterr.ts`: Songsterr (api `/api/songs`, `/api/meta/<id>`, ноты партии — JSON на CDN
  `dqsljvtekg760.cloudfront.net/<song>/<revision>/<image>/<part>.json`). Длительности уже с точками и триолями, струна 0 —
  тонкая, `marker` у такта — название части. Найденная песня запоминается в `songMeta.sst` (null — не нашли), партия —
  `songMeta.sstTrack`. `components/TabPlayer.tsx` рисует таб SVG-строками под ширину и играет синтезом (скорость, петля
  A–B по тактам, метроном, курсор). Вкладка «Табы» — `components/SongTabs.tsx` (+ фингерстайл/другие версии, текстовый таб UG).
  Под частями текста «Вступление/Проигрыш/Соло» — раскрываемый таб лид-партии (`Sheet.sectionExtra`, `sectionRange`).
- **Аккорды по табам** — `lib/autochords.ts` (+ `autoChords(meta)` в `lib/songsterr.ts`): ноты всех партий (без вокала и
  барабанов) по половинам такта → гистограмма + бас → аккорд (шаблоны, бонус за бас и за аккорды тональности, тональность
  по Крумханслу), сглаживание проходящих. Слова — `newLyrics` вокальной партии (слоги через «-», по одному на спетую ноту),
  аккорд ставится над слогом, на котором меняется; нет слов — сетка по 4 такта. Песни `sst-…` получают такой текст сами
  (`SavedSong.auto = "songsterr"`, плашка в тексте); у песен без аккордов — кнопка «Проставить аккорды» (`AutoChordsOffer`).
- **Гармония по табам** учитывает многоголосие: аккорды (2+ звука) и бас весят много, одиночные ноты рифа — мало; качества
  только мажор/минор/7/m7/5 (квинта — если терции почти нет; в «аккордовых» песнях квинта заменяется аккордом тональности);
  аккорд на такт, половина — только при явной смене. Сетка без слов сжимает повторы блоков 1/2/4 строк в «×N»
  (Sheet показывает «×N» приглушённо, это не аккорд, но в нумерации `data-ci` участвует).
- **Слова из интернета** — `lib/lyrics.ts`: LRCLIB (`lrclib.net/api/search`, через `net`), обычный и синхронный текст.
  `autoChords` берёт их, если в табе слов нет: есть мелодия вокала — строки по её фразам (`looseSyllables`), нет — по
  времени строк LRC, переведённому в такты по темпу таба (`timedSyllables`, длина подгоняется под запись ±15%).
  Пауза между строками > 9 с — новый куплет. При сбое сайта результат не кэшируется. Источник — `SavedSong.lyricsFrom`.
- **Свои слова и редактор**: «📝 Добавить слова» — `autoChordsWithText` раскладывает строки по фразам вокальной мелодии
  (`looseSyllables`, слоги по гласным — `syllabify`); результат или просто слова открываются в `components/ChordEditor.tsx`
  (палитра + нажатие на слово). «✏️ Аккорды» есть у любой песни; своя песня (`u-…`) обновляется, остальные сохраняются
  новой своей песней.
- **Табы**: нажатие на такт — играть с него до конца; «🔁 Петля» — выбор первого и последнего такта.
- **Бой и фишки** (вкладка «Практика», `components/SongFlavor.tsx`) берут ритм-партию Songsterr (`useSongTabs(…, "rhythm")`,
  выбор партии во вкладке «Табы» на неё не влияет). `lib/strum.ts`: бой по частям — самый частый рисунок такта, направление
  по правилу маятника (стрелки авторов табов непоследовательны), библиотека боёв, подбор по темпу/размеру, `playStrum`.
  `lib/embellish.ts`: аппликатуры из оригинала (`originalShapes` + `isSpecial`), украшения в 1–2 пальца от основной
  формы (`variantsFor`), басовые переходы по гамме тональности без скачков через октаву (`bassWalks`).
- **Прокрутка текста** — `components/ScrollDock.tsx` (панель над нижним меню хаба): «За игрой» — `lib/follow.ts` слушает
  микрофон, сравнивает хромаграмму только с аккордами песни и ближайшими следующими (до 4) и двигает позицию; аккорды в
  `Sheet` пронумерованы `data-ci`, нажатие на аккорд в этом режиме — «я здесь». «Авто» — первая скорость по длине
  оригинала (`songMeta.original.d`), ручная подкрутка вперёд/назад меняет скорость, она сохраняется в `songMeta.scrollSpeed`.
  «Тап» — касание низа/верха текста; PageDown/PageUp/стрелки (педаль) работают всегда.
- **Текст песни** — `lib/sheet.ts`: одна модель для UG (`[ch]`, `[tab]`), своего ChordPro-lite (`[G]слова`, `[[Припев]]`)
  и вставленного текста (строки из аккордов над словами, табы `e|---`). Аккорды хранятся с колонкой → транспонирование и
  перенос строк под ширину экрана (`wrapPair`, табы — по тактам `wrapTab`). Рисует `components/Sheet.tsx`.
- **Аккорды** — `lib/chords.ts`: разбор любого обозначения (H = B, слэш-аккорды, sus/add/dim/m7b5…), поиск аппликатур по
  грифу с пальцами и баррэ (`voicings`), канонические формы в `STANDARD` всегда первые, обратная задача `identify`.
  `resolveChordShape` (старые тренажёры) = `bestShape`.
- **Видео**: уроки к темам — `data/videos.ts`, генерирует `node scripts/fetch-videos.mjs [тема…]` (поиск YouTube,
  ранжирование, проверка встраивания; при ограничениях YouTube ждёт и не затирает найденное). Руками файл не править.
  Разборы конкретной песни и оригинал ищутся на лету (`lib/youtube.ts`) и сохраняются в `songMeta`.
- **Учёба** — `data/paths.ts`: пути из шагов lesson/video/exercise/practice/song, прогресс — коллекция `learn`
  (id шага). id шагов не менять.
- Тренажёры «Смена аккордов» (`?chords=`) и «Джем» (`?chords=&key=`) принимают аккорды песни.
- Звук, микрофон, высота тона — библиотека `audio` (`@modules/audio`); там же стабилизатор показаний. Гитарный синтез и
  аккомпанемент (`lib/audio/guitar-synth.ts`, `backing.ts`) — здесь.
- Прогресс тренажёров и дни занятий — по-прежнему kv через `lib/storage.ts` (`guitarhub_train-stats`,
  `guitarhub_practice-days`, `guitarhub_breath-log`). Записи голоса — файлы хаба + коллекция `recordings`.
