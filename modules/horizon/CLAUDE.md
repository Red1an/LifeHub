# Кругозор

Порция дня для расширения кругозора: 10 рубрик (в т. ч. цитата и анекдот — чтобы запомнить и рассказать), «Угадай год», задачки, «копнуть глубже» и повторение.

## Как устроено

- Экран «Сегодня» — плитки рубрик (`pages/Today.tsx`), нажатие открывает рубрику на весь экран (`pages/Reader.tsx`,
  `/k/:kind`, из архива `/d/:day/:kind`): снизу «← / все / дальше», свайп влево-вправо, открытая рубрика = прочитана.
- Порция генерируется при первом открытии дня (`lib/store.ts` → `useDaily`, очередь `runCard`, не больше 3 запросов
  к нейронке сразу). Генерация — `lib/gen.ts`, по одной функции на рубрику.
- Факты берутся из источников, нейронка их только объясняет (`lib/sources.ts`):
  - «В этот день» — `ru.wikipedia.org/api/rest_v1/feed/onthisday/all/MM/DD` (события, родились, ушли, праздники);
  - «Знаете ли вы» — анонсы из `Шаблон:Знаете ли вы`, разгадка — по тексту статьи;
  - стихи — Викитека, поиск по первой строке из `lib/poems.ts` (только общественное достояние);
  - технологии — главная Hacker News (повод), картины — статья Википедии (картинка из summary);
  - цитаты и анекдоты — из знаний нейронки: цитаты только с подтверждённым авторством, анекдот делится на
    `setup` и `punchline` (концовка открывается по нажатию).
- Задачка: сложность `prefs.level` (1–5, дробная) растёт на 0.5 за решение с первой попытки без подсказок
  и падает на 0.5 за «сдаюсь». Ответ word — варианты через «|», спорный ответ сверяет нейронка.
- Повторение: у карточки есть `recall {q, a}` → коллекция `recall`, интервалы 1/3/7/21/60 дней, вопросы — только
  по прочитанным карточкам (`done`).

## Данные

- Коллекция `cards`, id `${day}_${kind}` (доп. задачки `${day}_puzzle_${n}`): `CardDoc` в `lib/types.ts`.
  `status: loading` старше 4 минут считается прерванным.
- Коллекции `recall`, `days` (события дня из Википедии), `games` («Угадай год»).
- kv `prefs` — интересы, выключенные рубрики, сложность задачек.
- kv `quick` — `{ items: QuickPuzzle[], at }`, последние 40 коротких задачек с вариантами. Их читает сервер
  (`server/focus.ts`) и показывает расширение Фокуса на экране «Зачем пришёл?», пока идёт ожидание —
  формат менять только вместе с `voice/browser-extension/focus/gate.js`.
